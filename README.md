# Multiplayer Baseball Gameplay System # 

A custom Minecraft Bedrock baseball gameplay system built for a multiplayer league community of 200+ members.

The project was created to support organized baseball games inside Minecraft, with custom mechanics for pitching, batting, fielding, scoring, and overall game flow.

## Features

- Custom pitching mechanics
- Batting and hit detection
- Baseball physics and projectile behavior
- Fielding and player interactions
- Outs and scoring systems
- Multiplayer game logic
- Custom items and entities
- Gameplay balancing based on player feedback

## Technologies Used

- JavaScript
- JSON
- Minecraft Bedrock Scripting API
- Minecraft Behavior Packs
- Git / GitHub
- Linux command line
- PuTTY / SSH

## Project Structure

- `scripts/` — JavaScript gameplay logic
- `entities/` — custom entity definitions
- `items/` — custom item definitions
- `functions/` — game functions and commands
- `manifest.json` — behavior pack configuration

## Development Process

This project was developed and maintained for a multiplayer league community with more than 200 members.

Player feedback was used throughout development to identify gameplay issues, troubleshoot bugs, adjust mechanics, and improve the overall experience.

The project was continuously tested during multiplayer gameplay and updated based on real user feedback.
